# Documents

This folder contains visual reference material for the tracked vehicle project. It supports the hardware, wiring, and control-system explanations used in the rest of the repository.

## Contents

| File | Description |
| --- | --- |
| `rc_vehicle.png` | Photo of the physical tracked vehicle platform. |
| `wiring_diagram.png` | Wiring diagram showing the ESP32, ESCs, BLDC motors, ultrasonic sensor, regulator, and battery connections. |
| `acc_closed_loop.png` | Closed-loop control diagram used to explain the P and PI controller implementation. |
