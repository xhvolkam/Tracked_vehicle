# Documents

This section contains visual reference material for the tracked vehicle project.

## Purpose

The files in this folder support the hardware and control-system documentation. They are used to understand the physical platform, wiring, and closed-loop control structure.

## Important Files

| File | Purpose |
| --- | --- |
| `rc_vehicle.png` | Photo of the tracked vehicle platform. |
| `wiring_diagram.png` | Wiring diagram for the ESP32, ESCs, BLDC motors, ultrasonic sensor, regulator, and battery. |
| `acc_closed_loop.png` | Closed-loop control diagram used in the P and PI controller section. |

## Role In The Project

Use this section when checking hardware connections or explaining how the measured distance, controller, PWM command, and vehicle motion are connected.
